# Fraud Detection Power BI Dashboard

## 📌 Project Overview
This project analyzes transaction data to identify fraudulent activities using Power BI visualizations.

## 📊 Dashboard Features
- Total Transactions Card
- Fraud vs Normal Donut Chart
- Date Slicer for filtering
- Interactive visuals
